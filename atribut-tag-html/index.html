Memahami Atribut Tag HTML

Informasi Tambahan untuk Mengontrol Perilaku dan Tampilan Elemen.

Apa Itu Atribut?

Atribut adalah **kata kunci khusus** yang ditambahkan pada **tag pembuka** elemen HTML untuk memberikan informasi tambahan tentang elemen tersebut, mengontrol perilakunya, atau menerapkan gaya.

// Sintaks Dasar Atribut <tag nama-atribut="nilai-atribut"> Konten </tag>

Atribut Global (Dapat Digunakan di Mana Saja)

Atribut ini berlaku untuk hampir semua tag HTML dan sangat krusial untuk styling (CSS) dan interaktivitas (JavaScript).

Demo ID dan CLASS

Teks ini menggunakan atribut id="unique-id" (Hanya untuk satu elemen).

Teks ini dan teks di bawah menggunakan class="styling-class".

Kelas bisa digunakan berulang kali pada elemen berbeda.

ID digunakan untuk penargetan CSS/JS yang sangat spesifik.
CLASS digunakan untuk mengelompokkan elemen yang berbagi gaya yang sama.

  • `id`: Pengenal unik untuk satu elemen.
  • `class`: Mengelompokkan elemen untuk styling yang sama.
  • `style`: Menentukan Inline CSS (gaya langsung pada elemen).
  • `title`: Menampilkan tooltip (teks kecil) saat kursor diarahkan ke elemen.
  • `hidden`: Atribut boolean untuk menyembunyikan elemen.

Atribut Spesifik Elemen (Wajib/Khas)

Atribut ini hanya berfungsi pada tag tertentu untuk fungsionalitas khusus.

Tag & Atribut Fungsi Contoh
<a href="" target=""> **`href`**: URL tujuan tautan.
**`target`**: Menentukan di mana tautan dibuka (misalnya _blank untuk tab baru).		 Buka Google
<img src="" alt=""> **`src`**: Sumber (URL/path) file gambar.
**`alt`**: Teks alternatif jika gambar gagal dimuat.
<input type="" placeholder=""> **`type`**: Jenis input (text, password, submit, dll).
**`placeholder`**: Teks petunjuk di kolom input.
